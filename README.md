## IPA Spelling Bee

An linguistics-themed puzzle inspired by the New York Times Spelling Bee, built with Pygame. Players construct valid words in an interactive GUI using characters from the International Phonetic Alphabet (IPA). Also features some educational information and trivia about the IPA!

## Daily Cryptoquote Puzzle

A daily cryptoquote puzzle made with quotes fetched from Zenquotes API. Users' save data is stored locally to prevent cheating and limit plays to once per day.
